# Laboratory 3 — Multi-Cloud Explorer

## Mission Overview
Evaluated AWS, Microsoft Azure, and Google Cloud Platform to recommend cloud solutions for different business scenarios. Compared services, analyzed strengths, and produced professional recommendations.

## Linux Server Investigation — KillerCoda
### System Information
- **Operating System**: Ubuntu 24.04.4 LTS
- **CPU**: 2–4 vCPUs, x86_64 architecture
- **Memory**: ~2–4 GB RAM
- **Disk Space**: ~20–40 GB storage

### Cloud Equivalent Services
If this Linux server were migrated to the cloud:

| Provider | Compute Service |
|---|---|
| **AWS** | Amazon EC2 — Elastic Compute Cloud (virtual machines) |
| **Azure** | Azure Virtual Machines (VMs) |
| **GCP** | Google Compute Engine (GCE) |

All three providers offer Linux-compatible virtual machines with matching CPU/memory/storage configurations.
