# Amazon Web Services (AWS) — Research

## Brief Overview
AWS, launched in 2006, is the world’s largest public cloud platform offering over 200+ full-featured services from data centers globally. It serves startups, enterprises, and governments with broad, deep capabilities across compute, storage, networking, AI, analytics, and more.

## Global Infrastructure
- 32 geographic **Regions** worldwide
- 102 **Availability Zones** (isolated locations within regions)
- Network of edge locations for low-latency content delivery

## Management Console
Web-based unified interface to provision, configure, and monitor all AWS services. Features search, service menu, dashboards, and access control.

## Four Core Services
1. **Amazon EC2** — Scalable virtual servers in the cloud
2. **Amazon S3** — Scalable, durable object storage
3. **Amazon VPC** — Isolated cloud network environment
4. **Amazon RDS** — Managed relational database service

## Three Advantages
- Widest selection of services and deepest feature coverage
- Mature ecosystem, massive community, and extensive documentation
- Flexible pricing and largest global footprint

## Typical Enterprise Use Cases
- Enterprise application hosting & legacy migration
- Big data analytics & data lakes
- Global e-commerce & high-traffic web applications
- Startup infrastructure with pay-as-you-go scaling
