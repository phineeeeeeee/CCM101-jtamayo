# Microsoft Azure — Research

## Brief Overview
Azure, launched in 2010, is Microsoft’s cloud platform tightly integrated with the Microsoft ecosystem (Windows, Active Directory, 365, .NET). It offers IaaS, PaaS, and SaaS across enterprise-grade services.

## Global Infrastructure
- 60+ **Regions** worldwide
- Most regions paired for disaster recovery
- Strong presence in North America, Europe, and Asia

## Management Console
Azure Portal — unified graphical interface with dashboards, resource groups, and role-based access control.

## Four Core Services
1. **Azure Virtual Machines** — Windows & Linux virtual servers
2. **Azure Blob Storage** — Scalable object storage
3. **Azure Virtual Network** — Private & hybrid cloud networking
4. **Azure SQL Database** — Fully managed cloud SQL

## Three Advantages
- Seamless integration with Microsoft products & hybrid cloud
- Enterprise-grade security & compliance
- Unified licensing & cost-effective for existing Microsoft customers

## Typical Enterprise Use Cases
- Organizations already using Windows Server, AD, & Microsoft 365
- Hybrid cloud & on-premises integration
- .NET application modernization
- Government & regulated industries
