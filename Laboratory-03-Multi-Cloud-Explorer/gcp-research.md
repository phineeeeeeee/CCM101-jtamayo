# Google Cloud Platform (GCP) — Research

## Brief Overview
GCP, launched in 2008, leverages Google’s own infrastructure and global network. It is a leader in containers, Kubernetes, open-source, and AI/ML innovation.

## Global Infrastructure
- 34 **Regions** worldwide
- Premium global network with high-speed private fiber
- Lower latency & consistent performance globally

## Management Console
Google Cloud Console — clean, modern interface with project-based organization & IAM.

## Four Core Services
1. **Google Compute Engine (GCE)** — High-performance virtual machines
2. **Google Cloud Storage** — Unified object storage
3. **Google VPC** — Global virtual networking
4. **Google Kubernetes Engine (GKE)** — Managed Kubernetes (originator)

## Three Advantages
- Industry leader in Kubernetes, containers, & AI/ML
- Superior global network & consistent pricing
- Strong open-source culture & developer-friendly tools

## Typical Enterprise Use Cases
- AI, machine learning, & data analytics workloads
- Cloud-native & microservices architectures
- High-growth startups & open-source teams
- Multi-regional & global applications
