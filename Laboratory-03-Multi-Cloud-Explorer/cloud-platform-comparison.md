## Analysis Questions

### 1. Which cloud provider offers the broadest range of services?
**AWS** offers the widest range — over 200+ services covering every category. Its massive ecosystem spans compute, storage, databases, analytics, AI, IoT, security, and enterprise tools with deeper third-party marketplace support than competitors.

### 2. Which provider best integrates with Microsoft technologies?
**Azure** is purpose-built for Microsoft environments. It natively integrates Windows Server, Active Directory, Microsoft 365, .NET, and Visual Studio with single sign-on, unified licensing, and hybrid tools like Azure Arc.

### 3. Which provider is strongest in AI and Kubernetes?
**GCP** leads here — it created Kubernetes and offers the most mature managed orchestration (GKE). Its AI/ML tools (Vertex AI, BigQuery, AutoML) are built on Google’s research, making it preferred for advanced workloads.

### 4. Which cloud platform would you personally choose and why?
I would choose **GCP** for cloud-native development and AI work due to its superior networking, open-source leadership, and modern developer experience. For general enterprise with Microsoft, Azure is clearer; for maximum service breadth, AWS wins — but GCP balances innovation and simplicity best.
