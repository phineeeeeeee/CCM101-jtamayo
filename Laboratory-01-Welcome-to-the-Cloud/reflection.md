# Reflection
Mission 1 was a really good start to our cloud computing activities! At first, I felt a little nervous using the Linux terminal because I’m still getting used to the commands. But as I went through each checkpoint step by step, I slowly got the hang of it.

Using KillerCoda was cool because I didn’t need to install anything on my laptop I could just use the Linux environment right in my browser. Creating my own user account, checking system info, and making folders helped me understand how to move around and organize files in Linux. I learned that even simple commands are really important, and you have to type them carefully or they won’t work!

Setting up my GitHub portfolio was my favorite part. I realized that it’s not just about doing the tasks it’s also about keeping everything neat and well-documented. Writing in Markdown and arranging my files properly showed me that documentation is just as important as the technical work itself.

This portfolio will be like my personal progress journal, and I’m excited to keep adding more projects to it.

Overall, this mission taught me that being a cloud engineer starts with the basics knowing Linux, staying organized, and documenting your work properly. I know there’s still a lot to learn, but this first activity gave me confidence and a solid foundation to build on in the coming lessons.
